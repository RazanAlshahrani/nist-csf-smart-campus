# NIST CSF — Smart Campus Assessment

## Overview
This university group assignment applies the NIST Cybersecurity Framework to a smart campus lab scenario.

The lab hosts student applications and IoT prototypes, with 20 staff members and 200 students. The assessment considers personal devices, cloud-based systems, a limited budget, and a moderate risk appetite.

## Assessment Scope
The report covers the five CSF functions used in the assignment:
- Identify
- Protect
- Detect
- Respond
- Recover

For each function, the assessment selects a category and subcategory, describes the current security state, defines a target state after one year, and proposes prioritized improvement actions.

## Areas Covered
- Asset inventory and device registration.
- Identity and access management.
- Network monitoring and security alerts.
- Incident response planning.
- Backups and recovery planning.
